# Portafolio Full Frontend (Vue 3 + Vite + Pinia)

## 1) Instalar
```bash
npm install
```

## 2) Configurar Supabase (opcional)
Copia y pega:
```bash
cp .env.example .env
```
Luego abre `.env` y pega tus claves reales.

## 3) Ejecutar
```bash
npm run dev
```

## 4) Compilar para GitHub Pages
```bash
npm run build
```

## Qué incluye
- Hero con Three.js interactivo
- Fondo con particles.js
- Glitch en títulos
- Cursor personalizado
- Typewriter en “Sobre mí”
- Parallax con GSAP + ScrollTrigger
- Cards 3D glassmorphism
- Neon glow (`#00d4ff`)
- Botón WhatsApp pulsante
- Modo oscuro/claro
- Easter egg (código Konami)
- Chat + contador de visitas con Supabase (o modo demo si no hay `.env`)
